# 피지컬 AI 메이킹 교안 웹앱

2026 AI·디지털 기반 융합·메이커교육 역량강화 직무연수의 **7~8차시·9~10차시 교안**입니다.
강사는 프로젝터로 발표하고, 연수생은 각자 노트북에서 같은 교안을 열어 따라 하며 설계를 저장하고 결과물을 제출합니다.

| | 내용 |
|---|---|
| 7~8차시 | 링비트와 바운더리 AI를 활용한 문제해결 작품 설계 — 서보모터·마이크로비트·AI 모델의 기능 익히기 |
| 9~10차시 | 링비트와 AI모델을 활용한 문제해결 작품 제작 및 수업 적용 — 공통과제 「바둑돌 나누기」 설계·제작·제출·발표, 학교 수업으로 |

## 주소

- 허브: https://actafoo.github.io/aimaker/ (짧은 주소 https://joo.is/aimaker)
- 7~8차시: https://actafoo.github.io/aimaker/78/
- 9~10차시: https://actafoo.github.io/aimaker/910/

연수생은 노트북의 크롬에서 엽니다. 별도 설치나 로그인은 없습니다.

## 교안에서 할 수 있는 것

**7~8차시** (저장하는 기능 없음, 서버는 열 때 한 번만 부름)
- 여는 영상: 문제 상황과 해결한 도구 영상을 슬라이드 안에서 재생
- 직접 만져 보는 체험: KNN 핸드포즈 다수결, AI 바꿔 끼우기, 손 높이로 서보 움직이기
- 블루투스 장치 이름 입력(노트북에만 저장), 코드 캡처 크게 보기
- 디자인 씽킹 다섯 단계와 아이디어 씨앗(아이디어 카드는 종이로 나눔)

**9~10차시** (연수생 기록은 서버에 저장)
1. 별명 등록 — 실명 대신 별명과 숫자 비밀번호 4자리
2. 설계 정리하기 — AI 모델, 나누는 방법(자유롭게), 받는 값마다 서보가 할 일
3. 모두의 계획 — 모두의 설계가 실시간으로 올라오는 보드
4. 만들기 자료 모음 — 예제 코드, 선 연결, 움직임 미리 보기, 안 될 때 확인할 것
5. 제출용 동영상 찍기 — 강사 구글 드라이브 폴더 또는 유튜브(일부 공개)로 올리기
6. 내 결과물 제출 — 작품 제목·설명·MakeCode 주소·영상 주소. 빈 칸이 있어도 제출됩니다
7. 작품 발표회 — 제출물마다 발표 쪽이 저절로 생기고, 하트를 누를 수 있음
8. 학교 수업으로 — 피지컬 AI의 역할, 기를 수 있는 역량, 지도 흐름, 학교 여건에 맞는 운영, 정해진 키트로 수업하기, 수업 준비 자료
9. 자료 — 모델별 예제 코드, 서보 각도·360° 서보 체험, 안 될 때 확인할 것, 바이브코딩, 재료 구입처

**강사 위치:** 강사가 관리자로 들어가 발표하면, 연수생 교안 아래 막대에 강사가 보고 있는 쪽이 빨갛게, 오른쪽에 「강사 N쪽」 버튼으로 보입니다(누르면 그 쪽으로 이동). 같은 교안일 때만 보이고, 관리자 기기가 둘이면 실제로 쪽을 넘긴 기기의 위치가 보입니다.

두 교안은 이어져 있습니다. 7~8차시 마지막 쪽에서 다음을 누르면 9~10차시 표지로, 9~10차시 첫 쪽에서 이전을 누르면 7~8차시 마지막 쪽으로 갑니다.

## 쓰는 법

| 동작 | 방법 |
|---|---|
| 넘기기 | `←` `→` 키, 또는 아래 막대의 버튼 |
| 전체 화면 · 목차 | `F` · `M` (목차에서 누르면 그 쪽으로 이동) |
| 특정 쪽으로 바로 | 주소 끝에 `#12`(번호), `#s-kits`(쪽 id), `#end`(마지막 쪽) |
| 관리자 화면 | 주소 끝에 `#admin` 또는 `Ctrl+Shift+A` → 관리자 비밀번호 |
| 교안 편집 | 관리자로 들어가 `Ctrl+Shift+E`(또는 관리자 › 교안 편집) |

관리자 화면에서는 강사 위치 알리기 켜고 끄기(발표하지 않는 기기는 끔), 설계 카드·제출물 숨기기와 고치기, 발표 순서 뽑기, 내보내기(JSON·CSV), 전체 초기화를 할 수 있습니다.
교안 편집에서는 화면의 글자를 바로 고쳐 파일로 저장하거나, 웹 주소에서 고친 내용을 담당자에게 보내고 쪽마다 메모를 남길 수 있습니다.

## 폴더 구성

```
AI메이커 연수/
├─ 배포하기.command      더블클릭하면 site 폴더를 GitHub Pages에 올림
├─ backend/
│  ├─ Code.gs            서버 코드(구글 Apps Script에 붙여 넣음)
│  └─ 설치 안내.md        서버 설치·새 버전 반영 방법, 구글 한도
└─ site/                 웹에 올라가는 교안
   ├─ index.html         허브
   ├─ deck-7-8.html      7~8차시 교안 (78/ 은 이 파일로 가는 주소)
   ├─ deck-9-10.html     9~10차시 교안 (910/ 은 이 파일로 가는 주소)
   ├─ yt.html            유튜브 중계 페이지 (아래 참고)
   ├─ assets/css · js · img · fonts
   └─ _backup/           고치기 전 파일 (웹에 올리지 않음)
```

주요 스크립트

| 파일 | 하는 일 |
|---|---|
| `config.js` | 연수 정보(과정명·날짜·장소·강사), 서버 주소, 유튜브 중계 주소, 강사 드라이브 폴더 주소 |
| `deck.js` | 슬라이드 넘기기, 목차, 아래 막대, 교안 사이 이동 |
| `store.js` | 서버와 주고받기(현황 받기, 저장, 몰릴 때 자동으로 다시 보내기) |
| `widgets.js` · `cards.js` | 별명 등록, 설계 정리하기, 모두의 계획, 제출 |
| `interact.js` | 체험 위젯, 하트, 슬라이드 안 영상, 그림 크게 보기 |
| `showcase.js` | 제출물로 발표회 쪽 만들기, 유튜브·드라이브 영상 넣기 |
| `admin.js` · `editor.js` · `review.js` | 관리자 화면, 교안 편집, 편집 보내기·메모 |

슬라이드 하나는 `<section class="slide slide--body" id="고유이름" data-section="목차 묶음" data-title="목차에 보일 제목"> … </section>`입니다.
배경은 `slide--cover`(표지) · `slide--body`(본문) · `slide--pixel`(파트 구분) · `slide--pastel`을 씁니다.

## 서버

- 구글 스프레드시트를 저장소로, Apps Script(`backend/Code.gs`)를 서버로 씁니다. 시트 탭: 설정·신청·제출·도움·하트·아이디어·카드·편집·메모.
- 시트가 원본이고, 서버는 자주 읽는 내용을 구글 캐시에 담아 빠르게 답합니다. 캐시 한 칸은 100KB까지라 큰 데이터는 여러 조각으로 나눠 담습니다.
- 저장은 한 번에 하나씩 차례로 처리합니다. 몰려서 「잠시 밀렸어요」가 오면 교안이 1.5·3.5·6·10초 뒤 자동으로 다시 보냅니다. 하트는 손을 멈춘 뒤 마지막 상태만 한 번 보냅니다.
- 현황은 실시간 화면(설계 정리하기·모두의 계획·제출·제출 현황·발표회)에 있을 때만 10초마다 받아 옵니다. 다른 쪽에서는 교안을 열 때 한 번만 받습니다.
- 강사 위치는 시트에 쓰지 않고 캐시에만 둡니다. 강사 화면은 쪽을 넘기고 멈추면 한 번 알리고, 연수생 교안은 15초마다 아주 작은 요청으로 받습니다.
- 가상 40명으로 실제 서버를 시험했습니다(저장·제출·하트 400건 넘게, 실패 0건). 구글 무료 계정 한도와 초기화 시점은 `backend/설치 안내.md`에 있습니다.
- `config.js`의 서버 주소를 비우면 서버 없이 이 브라우저에만 저장하는 데모 모드로 돕니다.

## 유튜브 영상

유튜브는 영상을 띄운 페이지 주소가 없으면 「오류 153」을 냅니다. 교안 파일을 더블클릭해서 열면 이 주소가 없으므로, 그때는 배포한 사이트의 `yt.html`을 거쳐 영상을 띄웁니다. 배포 주소로 열면 바로 띄웁니다. 어느 쪽이든 인터넷 연결이 필요합니다.

## 배포

`배포하기.command`를 더블클릭하면 `site` 폴더를 GitHub 저장소 `actafoo/aimaker`에 올리고, 1~2분 뒤 GitHub Pages 주소에 반영됩니다.
- iCloud에만 있는 파일을 먼저 내려받고, `_backup`은 올리지 않습니다.
- 공개본의 데모 비밀번호는 비우고, 브라우저가 예전 CSS·JS를 쓰지 않도록 주소에 버전 번호를 붙입니다.

서버 코드를 고쳤을 때는 따로 Apps Script에 붙여 넣고 「배포 관리 → 새 버전」을 해야 합니다(`backend/설치 안내.md`).

## 개인정보와 결과물

- 실명을 받지 않습니다. 별명과 숫자 비밀번호 4자리만 쓰고, 비밀번호는 알아볼 수 없게 바꿔 저장합니다.
- 작동 영상은 얼굴·목소리 없이 손과 작품만 찍습니다.
- 제출한 결과물은 연수 뒤에도 지우지 않고 공유합니다.
