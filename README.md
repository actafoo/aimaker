# 피지컬 AI 메이킹 교안 (9~10차시)

2026 AI·디지털 기반 융합·메이커교육 역량강화 직무연수
「링비트와 AI모델을 활용한 문제해결 작품 제작 및 수업 적용」 HTML 슬라이드 교안입니다.
강사가 발표하는 화면이면서, 연수생이 각자 노트북에서 열어 **도전과제 카드를 읽고, 신청하고, 기록을 재고, 결과물을 제출**하는 화면이기도 합니다.

## 수업의 뼈대: 도전과제 카드 (2026-11-10)

모든 과제는 카드 한 장, 네 칸입니다. 카드를 **고르면 도전**, 직접 **쓰면 발명**이고, 어느 쪽이든 같은 네 칸으로 만들고, 재고, 고칩니다.

| 칸 | 담는 것 | 개념 |
|---|---|---|
| ① 상황 | 누가, 어디서, 어떤 불편을 겪나 | 발명 |
| ② 조건 | 마이크로비트·링비트, 서보 2개 이하, AI 모델 1개, 골판지 | 메이커 (조건은 정하고) |
| ③ 성공 기준 | 짝이 심판이 되어 재는 방법과 기록 이름 | 피지컬 AI의 피드백 |
| ④ 해결 | 비워 둠. 막힌 사람을 위한 시작 힌트만 | 메이커 (해결은 열고) |

110분 흐름: 카드 확인 10분 → 만들기 30분 → 1차 기록 10분 → 쉬는 시간 → 고치기·2차 기록·제출 15분 → 같은 카드끼리 발표 20분 → 우리 반 카드 쓰기 15분.
고장 찾기는 감지(AI 모델)·판단(마이크로비트)·행동(서보·구조) 세 칸으로 나눠 봅니다(「어디서 틀렸나요?」 쪽).

지금 카드 5장: 바둑돌 분류기(이미지분류) · 움직이는 다리(이미지분류) · 주문한 만큼만, 디스펜서(핸드포즈) · 손 대지 않는 로봇팔(모션인식) · 내가 쓰는 카드(모델 자유).
예전 7개 과제는 `_backup/20261110-141235-card/assets/js/challenges.js`에 있습니다.

## 저장 방식

- `config.js`의 `apiUrl`에 구글 시트 Apps Script 웹 앱 주소가 있으면 **온라인 모드**입니다.
  - 신청·제출이 모든 화면에 몇 초 안에 공유됩니다.
  - 기록은 구글 시트의 `설정 / 신청 / 제출 / 도움 / 하트 / 아이디어` 탭에 쌓입니다. 1차·2차 기록과 고친 것은 `제출` 탭 맨 뒤 세 열입니다.
  - 정원과 관리자 비밀번호는 서버에서 확인합니다.
- `apiUrl`이 비어 있으면 **데모 모드**입니다. 기록이 각자의 브라우저에만 남습니다.
- 서버 설치 방법은 프로젝트 폴더의 `backend/설치 안내.md`에 있습니다(이 저장소에는 올리지 않습니다).

### 슬라이드 추가

`components.html` 맨 아래 "슬라이드 뼈대"를 복사해 `deck-9-10.html`의 원하는 위치에 붙입니다.

- 배경 4가지: `slide--cover`(표지) · `slide--body`(본문) · `slide--pixel`(섹션 구분) · `slide--pastel`(발표회)
- `data-section`: 목차에서 묶일 이름
- `data-title`: 목차에 보일 제목
- 쪽 번호와 꼬리말은 자동으로 붙습니다.

카드 상세(카드마다 한 장)와 작품 발표회 슬라이드는 `challenges.js`와 제출물로 **자동 생성**됩니다. HTML에서는 `<div data-generate="...">` 자리만 있습니다.

## 조작하는 슬라이드

HTML 교안이라서 넣은 기능입니다. 코드는 `assets/js/interact.js`에 모여 있습니다.

| 쪽 | 기능 | 서버 새 버전 필요 |
|---|---|---|
| 오늘의 흐름 | 연수 날(`config.js`의 `date`) 실제 시각에 맞춰 흐름 막대에 **지금 여기**를 표시. 미리 보려면 주소 끝에 `?now=16:35` | 아니요 |
| 카드 한눈에 보기 | 위의 모델 태그를 누르면 그 모델 카드만 진하게, **빈자리만** 버튼 | 아니요 |
| 모델별 코드, 안 될 때 확인 | 신청한 과제의 모델 코드를 **내 모델**로 강조, 다른 모델은 흐리게 | 아니요 |
| 퀵 프로토타입 · 타이머 | **모두 같은 타이머**: 관리자가 시작·멈춤·+5분. 연수생 화면은 같은 시간이 흐르고, 다른 쪽에 있어도 위 가운데에 남은 시간 | 예 |
| 서보 각도 감 잡기 (새 쪽) | 슬라이더로 각도를 바꾸면 서보 팔이 실제 속도로 돌아감. 두 각도 번갈아 + pause가 짧으면 끝까지 못 가는 것까지 | 아니요 |
| 안 될 때 다섯 가지 확인 | 줄을 눌러 체크, **도움 요청**을 보내면 대기 순서가 보이고 관리자에게 알림 | 예 |
| 1차 기록 재기 | 1차·2차 기록, 어디서 틀렸나(감지·판단·행동), 고칠 것을 적어 두면 **제출 창에 자동으로 채워짐** | 아니요 (이 노트북에만 저장) |
| 결과물 제출 | 1차 기록·2차 기록·고친 것 칸 | 예 |
| 작품 발표회 | 작품마다 **기록 1차 → 2차**와 고친 것, **하트**(내 작품은 못 누름). 관리자의 **발표 순서 뽑기**는 같은 카드끼리 모은 뒤 섞음 | 예 |
| 우리 반 카드 모으기 | 연수생이 우리 반 카드(상황 + 성공 기준)를 한두 문장으로 올리면 모두의 화면에 모임 | 예 |

- **서버 새 버전 필요**: `backend/Code.gs`를 Apps Script에 새로 붙여 넣고 새 버전으로 배포해야 켜집니다(`backend/설치 안내.md`). 예전 서버면 이 기능들은 꺼지고 원래 화면(손 들기 안내, 이 화면만의 타이머)으로 보입니다.
- **내 모델 강조**는 `data-model="핸드포즈 이미지분류"`처럼 표시한 요소에 붙습니다. 다른 슬라이드에도 같은 속성을 달면 똑같이 동작합니다.
- 데모 모드에서는 모든 기능이 이 브라우저 안에서만 동작합니다(타이머는 누구나 조작).

## 화면에서 바로 글자 고치기 (편집 모드)

1. 교안에서 관리자로 들어갑니다 (`Ctrl+Shift+A`).
2. 오른쪽 위 **편집** 버튼을 누르거나 `Ctrl+Shift+E`를 누릅니다.
3. 점선이 생기는 글자를 눌러 고칩니다. Enter(또는 Shift+Enter)는 줄바꿈, Esc는 끝입니다.
   - 도전과제 제목·질문, 공통 조건 한 줄, 표지의 연수 정보는 한 줄짜리 칸이라 Enter를 누르면 고치기가 끝납니다.
4. **저장**을 누르거나 `Ctrl+S`를 누릅니다.
   - 크롬·엣지에서는 처음 한 번 `site` 폴더를 고르면, 그 안의 파일을 직접 고칩니다.
   - 사파리 같은 다른 브라우저에서는 고친 파일을 내려받습니다. 같은 이름 파일과 바꿔 넣으면 됩니다.

고친 내용이 저장되는 곳:
- 슬라이드 글자 → `deck-9-10.html`
- 도전과제 설명·공통 조건 → `assets/js/challenges.js`
- 표지의 연수 정보 → `assets/js/config.js`

교안을 열고 처음 저장할 때, 고치기 전 파일을 `site/_backup/날짜-시각/`에 남깁니다. 같은 창에서 이어서 저장할 때는 새로 남기지 않습니다. 필요 없으면 지워도 됩니다.
그림, 배치, 슬라이드 추가·삭제는 편집 모드로 할 수 없으니 파일에서 고칩니다.

## 관리자

교안에서 `Ctrl+Shift+A`를 누르거나 주소 끝에 `#admin`을 붙인 뒤 비밀번호를 입력합니다. 온라인 모드에서는 `Code.gs` 맨 위에 정한 비밀번호, 데모 모드에서는 `config.js`의 비밀번호입니다.

- **정원·마감**: 카드별 정원(기본 6명, 서버를 쓰면 `Code.gs`의 `DEFAULT_CAPACITY`), 카드별·전체 신청 마감
- **신청 명단**: 빼기, 다른 과제로 옮기기, 직접 추가(비밀번호 0000)
- **도움**: 대기 중인 도움 요청(막힌 곳, 확인한 것, 메모). 도와준 뒤 **처리**. 새 요청이 오면 알림이 뜨고 오른쪽 위 관리자 버튼에 개수가 붙습니다. 「안 될 때 다섯 가지 확인」 쪽의 대기 줄에서도 ✓로 처리할 수 있습니다.
- **제출물**: 고치기(1차·2차 기록, 고친 것 포함), 숨기기, 발표에 넣기, 발표 순서 바꾸기, 삭제
- **발표자료**: 발표 슬라이드로 이동하기, 발표 순서 뽑기(같은 카드끼리 모은 뒤 무작위), 작품별 하트 수. "발표 파일 저장"은 발표 슬라이드만 HTML 파일 하나로 저장합니다(현장 인터넷 대비용. 영상 재생은 인터넷 필요).
- **데이터**: JSON·CSV(엑셀) 내보내기, JSON 가져오기, 샘플 6개 넣기·지우기, 전체 초기화

관리자로 들어가면 신청 현황판에 마감 버튼, 이름 옆에 빼기(×) 버튼도 보입니다. 타이머 쪽에는 시작·멈춤·+5분·처음으로 버튼이 보이고(연수생 화면에는 없음), 우리 반 카드 벽의 모든 카드에 지우기(×)가 보입니다.

연수생 본인 확인은 이름과 숫자 4자리 비밀번호로 합니다. 비밀번호는 신청을 바꾸거나 결과물을 고칠 때만 씁니다.

## 인터넷에 다시 올리기 (배포)

`site` 폴더에서 고친 뒤, 프로젝트 폴더의 **`배포하기.command`**를 더블클릭합니다. 1~2분 뒤 인터넷 주소에 반영됩니다.

- 공개본에는 `config.js`의 데모 비밀번호를 비워서 올립니다.
- CSS·JS 주소 끝의 `?v=dev`는 올릴 때 파일 내용에 따른 버전 번호로 바뀝니다. 브라우저가 예전 파일을 섞어 쓰지 않게 하려는 것이니 지우지 마세요.
- 올리기 전에 iCloud에 내려가 있는 파일을 먼저 이 Mac으로 받습니다.
